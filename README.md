# 德语 B1/B2 学习工具箱

中文母语者的德语 B1/B2 本地学习工具：单词 SRS 卡组、语法专题练习、错题本、学习统计、听力精听。
**纯本地运行，零构建、零外部依赖、不联网。**

## 一、技术选型（二选一之说明）

**选择：纯前端 HTML/JS（零构建）+ Node 静态服务 + Node 运行自检。**

理由：

1. **无任何第三方依赖**：界面、图表（自绘 SVG）、语音（浏览器内置合成）都不需要安装包，也不依赖 CDN / 在线 API / 在线字体，满足「无外网假设」。
2. **逻辑与渲染天然可分离**：核心逻辑（SRS 调度、判分、错题、统计、持久化）放在 `js/core/`，全部为不触碰 DOM 的 ES 模块；同一批模块既被浏览器加载，也被 Node 直接 `import` 跑自检，逻辑层只有一份实现，测试即测真实代码。
3. **对比 Python 本地应用**：Python 桌面方案（tkinter 等）无法同时满足「零构建零安装 + 浏览器级排版（逐句解析、卡片动效）+ 语音朗读」；且 Python GUI 的自动化自检要复杂得多。Node 在本机已具备，用于跑自检与静态服务，无需任何 `npm install`。
4. **一键启动成本低**：`start.bat` 优先用 Node 起本地服务（ES 模块需要 http 协议），缺失时自动退回 Python 内置服务器；两者都按常见安装位置逐一探测，即使没写进系统 PATH 也能启动。

## 二、持久化选型（三选一之说明）

**选择：localStorage（键名 `dwt.db.v1`，结构版本号 v1）。**

理由：零配置、随浏览器自动持久化、同步 API 简单可靠；不选本地 JSON 文件是因为浏览器出于安全不能直接写盘，需要额外后端服务；不选 sqlite 是因为浏览器端无原生支持，需引入原生模块（违背零构建）。
为防数据丢失，「数据管理」页提供**导出 / 导入备份文本**功能；数据损坏时自动回退为空库而不崩溃。

### 数据结构（钉死，版本 1）

```text
dwt.db.v1 = {
  version: 1,
  profile:  { createdAt },                     // 首次使用时间
  settings: { dailyGoal, timeOffsetMs, ttsRate, lastDeckId, lastTopicId, demoSeeded },
  states:   { [卡片ID]: { id, algorithm, difficulty, halfLife, memoryReviewedAt, memoryTargetReached,
                         interval, reps, lapses, due, lastReviewed, lastRating, totalReviews, history } },
  customCards: { [卡片ID]: { id, deckId, term, pos, zh, example, exZh, level } },
  userDecks:  [ { id, name, level } ],
  events:     [ { ts, type: 'card'|'quiz'|'listening', deck?, topic?, qtype?, correct, rating? } ],
  mistakes:   [ { id, source, module, refId, topicId, stem, userAnswer, correctAnswer,
                  explanation, ts, wrongCount, mastered, masteredTs, lastReviewTs, reviewCount } ],
  quizStats:      { [专题ID]: { attempts, correct } },
  listeningStats: { [句子ID]: { plays, best } }, // plays 为自检提交次数；best 为 0/100 通过标记
}
```

听力统计沿用 v1 字段名：`plays` 实际表示听写自检提交次数，点击「自检」或按 Enter 各计一次，包含空答案和重复提交；正常及慢速播放均不计数。`best` 仅记录是否曾通过（0 为尚未通过、100 为曾通过），不是最佳相似度分数，页面按通过状态展示。
每次成功保存的自检提交同时写入一条 `type: 'listening'` 学习事件，`correct` 表示是否通过。学习量、目标进度、连续学习天数及正确率包含这些自检记录；听力播放不参与统计。事件流水最多保留最近 8000 条，逐句自检次数则持续累计。
听力自检的次数、事件和错题一次保存；存储不可写时回滚并提示「未保存」，可重试。输入法确认与长按重复 Enter 不触发提交，保存等待期间忽略重复事件，保存完成后主动重提交仍逐次计数。改写答案会清除旧判分，Enter 自检保留输入框与焦点。
多标签的听力提交通过浏览器原生 Web Locks 串行保存，并同步已保存次数。建议使用本地启动地址或 HTTPS；不支持 Web Locks 的浏览器会提示仅使用一个学习标签，此时仅刷新后再写入，无法保证同时写入不冲突。其他学习模块未新增同一锁的并发事务，请避免跨模块同时保存。

### 记忆算法：DHP-HLR + SSP-MMC

背卡采用用户提供的 KDD 2022 与 TKDE 2023 论文共同的方法，以 2023 年扩展版的 DHP-HLR 参数替代原 SM-2：

- 记忆状态包含难度 `d` 与半衰期 `h`（天），回忆概率为 `p = 2^(-实际经过天数/h)`。首次学习使用 `h = -1/log2(max(0.925 - 0.05d, 0.025))`；缺少德语词条的群体难度数据，统一以 `d=5` 初始化。
- 跨天回忆成功使用 `h' = h(1 + exp(3.252)d^(-0.3855)h^(-0.1471)(1-p)^(0.8214))`；失败使用 `h' = exp(1.003)d^(-0.1524)h^(0.2648)(1-p)^(-0.01736)`，随后难度增加 2、最高 18。这些系数沿用作者代码，尚未在本用户或德语词库上重新拟合。
- SSP-MMC 通过 Bellman 值迭代最小化达到目标半衰期的累计期望复习成本。成功／失败成本为 3／9 秒，目标半衰期为 360 天。半衰期按 `base=1.05` 对数网格离散，共 18 × 162 = 2916 个状态；候选动作是作者实现的整天间隔集合 `1…max(1, round(h·log2(1/0.3)))`。状态索引沿用最近格点，但未达 360 天的状态不提前映射到终点；终点显式设为 360 天。收敛检查覆盖所有状态，最大残差小于 `1e-8`。最优性只针对该模型、成本与有限网格，不代表真实学习效果已经验证。
- 策略已存入 `js/data/ssp_policy.js`，浏览器不做迭代、不联网。开发时可执行 `node scripts/build_ssp_policy.js` 重建，用户启动不需要该步骤。算法移植自 [maimemo/SSP-MMC-Plus](https://github.com/maimemo/SSP-MMC-Plus)（MIT，研究复现仓库，最近推送核验为 2024-03-14）。选择轻量 JavaScript 移植，保持项目零依赖；来源提交、论文与完整许可见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。
- 论文的反馈为二元回忆结果，页面使用“不会／会”；旧“模糊”评分按回忆成功兼容。按钮预览与实际保存使用同一调度函数，实际逾期时间会影响记忆更新。
- **当日重练是应用适配**：不会的词仍在本轮重练，存储到期设为 10 分钟；间隔少于 1 天的反复练习不增加或重置长期半衰期，也不覆盖长期模型时间锚点，避免短期记忆被当作跨天巩固。首次学习不管评分均初始化模型。长期调度的目标半衰期达到 360 天后按论文终止调度：使用 `memoryTargetReached` 和有限哨兵到期值，保留卡片及所有历史，并从复习队列和待复习统计排除；这不等于永久不会遗忘。
- **旧数据兼容**：仍使用 `dwt.db.v1`。加载和导入旧备份不改到期时间及复习次数；卡片下次评分时按现存的最多 30 条历史初始化 DHP 状态。历史已截断会标记 `memorySource=partial-history`，完全无历史时从中性初值开始（`legacy-baseline`），不伪造丢失记录。旧 `ef` 字段保留用于备份兼容，不再参与调度。
- 本实现采用两篇论文共有的 **DHP-HLR + SSP-MMC** 分支，未引入扩展版的 GRU-HLR、神经网络权重或用户参数训练。用户附加的 `.ris` 是 DOI 引用，原始数据集未下载；《记忆算法研究 1.0》目录为背景研究报告，不包含可运行源码或训练权重。

## 四、快速开始

1. 双击 `start.bat`（自动选择 Node 或 Python 启动本地服务并打开浏览器）。
2. 也可手动：`node server.js` 后访问 `http://127.0.0.1:8123/index.html`。
3. 运行自检：双击 `selftest.bat`，或命令行 `node js/selftest/run_all.js`。

### 运行环境探测（不依赖 PATH）

很多机器上 Node.js / Python 装好了但**没有写进系统 PATH**，此时用 `where node` 会扑空、脚本一闪而过。
`start.bat` / `selftest.bat` 因此按以下顺序逐个探测，命中即用：

| 顺序 | 运行时 | 探测位置 |
| --- | --- | --- |
| 1 | Node.js | 系统 PATH → `%USERPROFILE%\nodejs\node.exe` → `%USERPROFILE%\nodejs\*\node.exe` → `%LOCALAPPDATA%\Programs\nodejs\*\node.exe` → `C:\Program Files\nodejs\node.exe` → `C:\Program Files (x86)\nodejs\node.exe` |
| 2 | Python | 系统 PATH（`py -3` / `python`）→ `%LOCALAPPDATA%\Programs\Python\Python3*\python.exe` → `C:\Python312\python.exe` → `C:\Python313\python.exe` |

若都未命中，脚本会**暂停并列出已检查的位置**，不会静默退出。

### 启动失败排查

| 现象 | 原因与处理 |
| --- | --- |
| 窗口一闪而过 | 旧版脚本只查 PATH。现版本已改为多位置探测并在退出前 `pause`；若仍闪退，请右键 `start.bat` → 用记事本打开确认内容是否为新版 |
| 提示端口被占用 | 服务会自动顺延到 8124、8125……并打印实际地址；如需固定端口，先关闭占用程序 |
| 提示未找到运行环境 | 按上面表格把 Node.js 装到默认路径，或在安装时勾选「添加到 PATH」 |
| 浏览器没自动打开 | 手动访问窗口里打印的地址（默认 http://127.0.0.1:8123/index.html ） |

## 五、自检（selftest）说明

- 覆盖 9 组共 **116 项自检**，使用固定输入、固定种子与虚拟时钟，无需真实等待即可模拟跨天复习（含连续推进 100 天的调度一致性）。记忆算法校验作者公式的独立参考数值、全部策略格点的 Bellman 条件、预览一致性、同日重练、逾期、终点、旧进度与备份往返。听力界面联动测试在 Node 中模拟 DOM、语音合成与 localStorage，直接调用实际页面和状态模块，不依赖额外安装包；补充输入法、保存等待、失败回滚、答案改写、异步语音错误与语音列表更新覆盖。
- 数据自检校验：B1/B2 各 ≥400 词、词条五要素齐全、全库无重复词条；题库题号唯一、四选一恰四选项且答案键有效、解析非空；听力句库 ≥30 且含解析。
- 退出码：全绿为 0，存在失败为 1（可用于流水线）。

## 六、人工冒烟指引

1. **背卡**：进入「背卡」→ 开始本轮 → 空格翻面 → 分别试「不会 / 会」。新词“会”后通常 1 天复习，此后按实际间隔与模型状态计算；“不会”在本轮重练。按钮预览应与备份中的到期时间一致；达到模型目标显示暂不安排复习。旧版“模糊”记录保留。
2. **跨天复习模拟（无需等待）**：进入「数据管理」→ 时间机器推进 1～7 天 → 回「背卡」，到期卡片立即进入队列；「学习统计」的到期分布同步变化。
3. **练习判分**：进入「语法练习」→ 任选专题 → 答错时立即显示正确答案与解析。
4. **错题收集 → 重练**：答错几题、背卡评几个「不会」→ 打开「错题本」可见对应条目（含你当时的错误答案）→「重练未掌握」→ 自评「已经会了」后条目标记掌握。
5. **听力统计一致性**：进入「听力精听」，分别点击正常、慢速播放，「已自检」次数和学习记录均不增加；输入听写后点击「自检」或按 Enter，每次提交增加一次自检次数和一条学习记录。空答案仍计一次失败，但不收集错题；重复提交逐次计数。回到「学习统计」，学习量增加、正确率按是否通过变化，最近记录显示「听力自检」；听力页以「曾通过 / 尚未通过」展示历史通过状态。
6. **演示数据**：地址栏加 `?demo=1`（如 `index.html?demo=1#/stats`）可写入一次演示学习记录，用于快速查看全部界面效果。
